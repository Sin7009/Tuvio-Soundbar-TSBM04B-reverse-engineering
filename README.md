## 💡 Простыми словами: Что было сделано?

Саундбар **Tuvio TSBM04B** от Яндекса — отличная акустическая система 5.1.2 с настоящим Dolby Atmos, но заводская прошивка содержала раздражающие недоработки:
1. **Саундбар сам выключался через 15 минут**, если смотреть тихий фильм или слушать подкаст.
2. **Беспроводные тыловые колонки регулярно отваливались** и теряли связь при затихании звука.
3. **Каждый раз при включении орал на громкости 15** (из 30) вместо того, чтобы включиться тихо или запомнить прошлый уровень.

### 🔍 В чём смысл реверс-инжиниринга и ЧТО ИМЕННО реверсировали?
Когда у разработчиков нет исходного кода прошивки от завода-изготовителя, используется **реверс-инжиниринг (обратная разработка)** — анализ готового бинарного файла прошивки с целью понять его устройство и изменить поведение.

#### Что именно было реверсировано:
1. **Формат контейнера `ota.bin` (Actions AOTA):** Мы расковыряли заголовок бинарного файла и математику вычисления 7 контрольных сумм CRC32.
2. **Слой защиты:** Сняли статичную 32-байтовую XOR-маску скрытия разделов.
3. **Загрузчик `mbrec.bin`:** Дизассемблировали двухэтапный бутлодер на ассемблере ARM Thumb-2.
4. **Код операционной системы Zephyr RTOS:** Нашли векторную таблицу процессора Cortex-M4 (`0x20010000`), алгоритм декомпрессии движка Actions LZ77 и отследили точные функции системных таймеров `k_work_delayable` и настройки детектора энергии звука.

## 💎 Какой CX (Customer Experience) мы предлагаем?

Раньше для модификации прошивок требовалось устанавливать Linux, компиляторы, Python, вводить сложные команды в консоли и рисковать окирпичить саундбар.

**Наш новый CX равен 3 простым кликам:**
- **Без установки программ:** Всё работает прямо в вашем браузере (на ПК, Mac, iPhone или Android).
- **Визуальная студия с подсветкой:** Вы передвигаете понятные слайдеры (время сна, громкость при включении, качество Bluetooth), видишь топологию колонок и изменения параметров на лету.
- **Автоматическая переупаковка:** При нажатии одной кнопки сайт сам мгновенно собирает прошивку, пересчитывает все контрольные суммы CRC32 и **скачивает готовый файл `ota.bin` прямо в папку Загрузки**.
- **Простая установка:** Записать файл на флешку и вставить в саундбар — процесс занимает 30 секунд!

## ✨ Что исправлено в модифицированной прошивке?

| Проблема | Заводское поведение | Исправленное поведение в патче |
|---|---|---|
| 🤫 **Выключение в тихих фильмах** | Выключался через 15 минут при тихих диалогах. | **Детектор тишины отключен.** Саундбар работает пока вы сами его не выключите (или через 4-8 часов). |
| 📶 **Отвалы тыловых колонок** | Пинг отключался при тишине, тылы засыпали. | **Ускорен пинг (50ms вместо 200ms)** и заблокирован уход RF-чипа 5.8GHz в сон. Связь мёртвая. |
| 🔊 **Оглушающая громкость 15 при включении** | Каждое включение — громкость 15. | **Стартовая громкость снижена до 6** + включена память последнего уровня из NVRAM. |
| 🎛️ **Звучание и Бас** | Гудящий бас на 160 Гц. | **Кроссовер сабвуфера смещён на 90 Гц** + усилены каналы высоты Dolby Atmos на +4 дБ. |
| 📻 **Bluetooth** | Стандартный битрейт 256 kbps. | **Разблокирован максимальный битрейт SBC Dual Channel (450 kbps)** + новое имя устройства `Tuvio Studio 5.1.2 Pro`. |

Мы сделали удобную **[Онлайн Веб-Студию](https://sin7009.github.io/Tuvio-Soundbar-TSBM04B-reverse-engineering/)**!

4. Готовый файл **`ota.bin`** автоматически скачается в папку «Загрузки» на вашем компьютере или телефоне!

## 💾 Пошаговая инструкция по прошивке саундбара с USB-флешки

> [!NOTE]
> Процесс занимает менее 1 минуты. Нужна обычная USB-флешка до 32 ГБ.

1. **Форматирование:** Отформатируйте USB-флешку в файловую систему **FAT32**.
2. **Копирование:** Положите файл **`ota.bin`** в самый корень флешки (других файлов на флешке быть не должно).
3. **Обесточивание:** Выключите саундбар из розетки 220V.
4. **Подключение:** Вставьте флешку в USB-порт саундбара, затем включите вилку обратно в розетку.
5. **Прошивка:** На дисплее саундбара замигает надпись **`UP`** (Updating) ~30–60 секунд, затем появится надпись **`OK`**.
6. **Готово:** Выключите саундбар из розетки, вытащите флешку и включайте обратно — всё работает!

## 🛠️ Для разработчиков и исследовательских целей

В репозитории содержится проверенный инструментарий `aota_tool.py` на Python 3 для работы с контейнерами прошивок Actions AOTA:

* `aota_tool.py` — Утилита распаковки и пересборки контейнера Actions AOTA со снятием слоя 1 XOR-маски и автоматическим пересчётом всех 7 контрольных сумм CRC32 (`header_crc32`, `data_crc32`, `zephyr.bin crc32` и т.д.).

### Быстрый запуск из консоли:

```bash
# 1. Распаковать оригинальный образ ota.bin
python3 aota_tool.py unpack ota.bin dec/

# 2. Модифицировать нужные бинарные разделы (param.bin, sdfs.bin)

# 3. Переупаковать готовый ota.bin с валидными CRC32
python3 aota_tool.py repack dec/ new_ota.bin
```
