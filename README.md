## 💡 Простыми словами: В чём суть проекта?

Саундбар **Tuvio TSBM04B** от Яндекса — отличное железо 5.1.2 с честным Dolby Atmos, но заводская прошивка содержит неприятные баги:
1. **Саундбар сам выключается через 15 минут**, если смотреть тихий фильм или слушать подкаст.
2. **Беспроводные тыловые колонки регулярно отваливаются** и теряют связь.
3. **Каждый раз при включении орёт на громкости 15** (из 30) вместо того, чтобы включиться тихо или запомнить прошлый уровень.

### 🔓 Почему это легко починить?
Саундбар построен на процессоре **Actions ATS2853** под управлением популярной открытой операционной системы **[Zephyr RTOS](https://github.com/zephyrproject-rtos/zephyr)**.

Самое главное — **производитель НЕ зашифровал прошивку сложными ключами и НЕ подписал её цифровой подписью (RSA/ECDSA)**! Целостность проверяется обычными контрольными суммами CRC32. Это означает, что **любой владелец может настроить параметры под себя и прошить саундбар обычной USB-флешкой**!

## ✨ Что исправлено в модифицированной прошивке?

| Проблема | Заводское поведение | Исправленное поведение в патче |
|---|---|---|
| 🤫 **Выключение в тихих фильмах** | Выключался через 15 минут при тихих диалогах. | **Детектор тишины отключен.** Саундбар работает пока вы сами его не выключите (или через 4-8 часов). |
| 📶 **Отвалы тыловых колонок** | Пинг отключался при тишине, тылы засыпали. | **Ускорен пинг (50ms вместо 200ms)** и заблокирован уход RF-чипа 5.8GHz в сон. Связь мёртвая. |
| 🔊 **Оглушающая громкость 15 при включении** | Каждое включение — громкость 15. | **Стартовая громкость снижена до 6** + включена память последнего уровня из NVRAM. |
| 🎛️ **Звучание и Бас** | Гудящий бас на 160 Гц. | **Кроссовер сабвуфера смещён на 90 Гц** + усилены каналы высоты Dolby Atmos на +4 дБ. |
| 📻 **Bluetooth** | Стандартный битрейт 256 kbps. | **Разблокирован максимальный битрейт SBC Dual Channel (450 kbps)** + новое имя устройства `Tuvio Studio 5.1.2 Pro`. |

## 🎛️ Как собрать свою прошивку без установки программ?

Мы сделали удобную **[Онлайн Веб-Студию](https://sin7009.github.io/Tuvio-Soundbar-TSBM04B-reverse-engineering/)**!

1. Перейдите на страницу **[Live Configurator Studio](https://sin7009.github.io/Tuvio-Soundbar-TSBM04B-reverse-engineering/)**.
2. Настройте нужные вам слайдеры (время сна, громкость при включении, качество Bluetooth).
3. Нажмите кнопку **«⚡ Собрать и переупаковать ota.bin»**.
4. Готовый файл **`ota.bin`** автоматически скачается в папку «Загрузки» на вашем компьютере или телефоне!

## 💾 Пошаговая инструкция по прошивке саундбара с USB-флешки

> [!NOTE]
> Процесс занимает менее 1 минуты. Нужна обычная USB-флешка до 32 ГБ.

1. **Форматирование:** Отформатируйте USB-флешку в файловую систему **FAT32**.
2. **Копирование:** Положите файл **`ota.bin`** в самый корень флешки (других файлов на флешке быть не должно).
3. **Обесточивание:** Выключите саундбар из розетки 220V.
4. **Подключение:** Вставьте флешку в USB-порт саундбара, затем включите вилку обратно в розетку.
5. **Прошивка:** На дисплее саундбара замигает надпись **`UP`** (Updating) ~30–60 секунд, затем появится надпись **`OK`**.
6. **Готово:** Выключите саундбар из розетки, вытащите флешку и включайте обратно — всё работает!

## 🛠️ Для разработчиков и реверс-инженеров

В репозитории содержатся утилиты на Python 3 для самостоятельной работы с файлами прошивки:

* `aota_tool.py` — Утилита распаковки/упаковки контейнера Actions AOTA со снятием слоя 1 XOR-маски и автоматическим пересчётом 7 контрольных сумм CRC32 (`header_crc32`, `data_crc32`, `zephyr.bin crc32` и т.д.).
* `unpack_zephyr.py` — Извлечение исполняемого бинарника ARM Thumb-2 `zephyr_code.bin` из прошивки Zephyr RTOS с валидацией векторов Cortex-M4 (`MSP = 0x20010000`, `Reset = 0x00000101`).
* `patch_firmware.py` — Скрипт бинарного патчинга порогов энергии, RF-таймеров и громкости.

### Быстрый запуск из консоли:

```bash
# 1. Распаковать прошивку из контейнера ota.bin
python3 aota_tool.py unpack ota.bin dec/

# 2. Распаковать код приложения Zephyr RTOS
python3 unpack_zephyr.py dec/zephyr.bin unpacked/

# 3. Применить патчи
python3 patch_firmware.py

# 4. Переупаковать готовый ota.bin для флешки
python3 aota_tool.py repack patched/ ota.bin
```
